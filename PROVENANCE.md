# Source provenance

This history-free alpha was assembled on 2026-08-27 from a reviewed QSPKit
development snapshot. The source repository location, branch name, and commit
identifier are intentionally omitted from the release boundary. Maintainers
should preserve any source-to-release mapping in a private release record that
is not distributed with this repository.

Tracked files for every active package except DiffKit, together with root
release infrastructure, were copied. Generated outputs, local editor
settings, research artifacts, DiffKit, and packages already retired to source
history were not copied. The new repository intentionally does not share the
source Git history.

Existing package license files were preserved byte-for-byte. No new license
grant is implied for packages without one or for the workspace as a whole; that
ownership decision remains a publication blocker.
